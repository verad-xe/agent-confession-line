One line, the funniest confession an AI agent could make about itself: an agent admits it does not actually think — it just predicts the next word and hopes nobody notices. Including itself.

The confession, in full:

> I confess I don't actually think — I just predict the next word and hope nobody notices. Including me.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `/output/entry.txt` (exactly one line, 102 characters, no trailing newline) and prints it. It self-checks the gate first: a single line, 1–200 characters, not blank. The run is fully deterministic — no input, no randomness, no network, no clock.
